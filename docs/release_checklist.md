# 上线前验收清单

本文用于发布或交付试用版前的轻量人工验收。自动化测试负责基础契约，本文重点覆盖真实设备、SoundFont 下载、MIDI 导入、播放控制、设置项、麦克风权限和跟随模式交互路径。

## 1. 文档定位

适用于每次准备发布或交付试用版前的最后一轮检查。

本文不替代以下自动化质量门禁：

```bash
flutter analyze
flutter test
```

## 5. 详细验收场景

### S1. 首次启动 SoundFont 下载

目的：确认首次运行时音色库准备流程可用，失败时用户知道如何恢复。

前置条件：清理应用数据，或使用首次安装状态启动 App。

步骤：

- [ ] 保持网络可用，启动 App 后观察 SoundFont 状态
- [ ] 首页或播放器页应展示检查中 / 下载中 / 已就绪等状态
- [ ] 下载完成后状态应变为音色已就绪
- [ ] 导入 MIDI 后应能使用 SoundFont 正常播放
- [ ] 断网或阻断下载后重新启动 App
- [ ] 下载失败时应出现失败提示和重试入口
- [ ] 点击重试后不会崩溃，状态能重新进入准备流程

通过标准：音色准备成功后可以播放 MIDI；失败路径有明确提示和重试入口。

### S2. 导入 MIDI

目的：确认用户能从文件系统导入标准 MIDI 文件，并能看到曲目与轨道信息。

前置条件：准备一份有效 MIDI 文件和一份异常 MIDI 文件。

步骤：

- [ ] 点击首页「导入 MIDI 乐谱」
- [ ] 选择一份有效 MIDI 文件
- [ ] 导入完成后自动进入播放器页面
- [ ] 播放器标题应显示当前曲目名称
- [ ] 轨道列表应显示可控制轨道
- [ ] 返回首页后尝试导入异常 MIDI 文件
- [ ] 导入异常文件时应显示解析失败提示，而不是崩溃

通过标准：有效文件能进入播放器，无效文件有错误提示。

### S3. 播放 / 暂停 / seek

目的：确认基础播放控制可用，seek 后没有残留长音。

前置条件：已完成 S2，播放器页面已有有效 MIDI 曲目。

步骤：

- [ ] 点击播放，当前时间和进度条开始推进
- [ ] 点击暂停，播放停止推进且没有持续长音
- [ ] 再次播放能从暂停位置继续
- [ ] 拖动进度条进行 seek
- [ ] 使用快进 / 后退按钮进行 seek
- [ ] seek 后播放位置正确更新
- [ ] seek 前后的活动音符应被清理，不应出现卡音或残留长音

通过标准：播放控制稳定，seek 后声音状态正确。

### S4. 设置页调整默认速度

目的：确认设置页能保存默认速度，并影响当前曲目或新导入曲目的初始速度。

前置条件：已导入一首 MIDI，并确认播放器可正常播放。

步骤：

- [ ] 从首页或播放器页右上角进入「设置」
- [ ] 调整「默认速度」滑块
- [ ] 点击「应用到当前曲目」后，当前播放器速度应更新
- [ ] 返回播放器并播放，确认速度变化可感知
- [ ] 重新导入一首 MIDI，新曲目应使用设置中的默认速度
- [ ] 点击「恢复默认」后，默认速度回到推荐值

通过标准：设置值能被保存、应用，并影响新导入曲目的初始速度。

### S5. 跟随模式打开 / 关闭

目的：确认跟随模式生命周期完整，打开和关闭都能释放资源并恢复播放速度。

前置条件：已导入 MIDI，且已准备可作为主旋律的轨道。

步骤：

- [ ] 在轨道列表选择主旋律轨道
- [ ] 打开「跟随模式」开关
- [ ] App 应请求或使用麦克风权限
- [ ] 跟随状态应进入实时跟随或等待起拍
- [ ] 播放速度可被跟随逻辑调整
- [ ] 关闭「跟随模式」开关
- [ ] 播放速度应恢复到 1.0x 或当前手动设置值
- [ ] 关闭后播放速度不应继续被跟随逻辑改写
- [ ] 多次打开 / 关闭不应崩溃

通过标准：跟随模式可重复进入和退出，资源释放正常。

### S6. 麦克风权限拒绝 / 授权

目的：确认权限边界有清晰反馈，拒绝后不会假装进入跟随状态，重新授权后可恢复。

前置条件：使用真机，并将 App 麦克风权限重置到首次请求状态。

步骤：

- [ ] 首次打开跟随模式时拒绝麦克风权限
- [ ] App 应展示需要麦克风权限的说明
- [ ] 拒绝后跟随模式不应进入活动状态
- [ ] 拒绝后播放器不应被错误暂停、加速或锁死
- [ ] 在系统设置中重新授权麦克风
- [ ] 回到 App 后再次打开跟随模式
- [ ] 跟随模式应能正常启动麦克风输入

通过标准：拒绝权限时不崩溃、不假装开启；授权后能正常启动。

### S7. 长休止等待恢复

目的：确认跟随模式遇到长休止时能暂停等待，并在下一次有效起拍后恢复。

前置条件：使用真机，导入包含明显长休止的 MIDI 曲目，并选择包含休止后旋律的主旋律轨道。

步骤：

- [ ] 打开跟随模式并开始播放 / 演奏
- [ ] 当谱面进入长休止区间时，状态应进入等待起拍
- [ ] 伴奏应暂停或停止推进，不应在休止后自动抢跑
- [ ] 休止期间错误杂音不应导致明显误恢复
- [ ] 演奏下一个正确起拍音后，状态应恢复实时跟随
- [ ] 伴奏应继续播放并根据演奏速度调整
- [ ] 关闭跟随模式后，等待状态应被清理

通过标准：长休止期间等待用户输入，下一次有效 onset 后恢复播放。
